# German (DE) regional profile first

## Context and Problem Statement

ORDO needs one concrete regional profile to start with.

## Considered Options

* Austria first
* Germany first
* International first

## Decision Outcome

Chosen option: "Germany first (FwDV 100, DV 102, status 1–9, Sichtungskategorien, DIVI MIND)", because the first test partners will be German organisations.

### Consequences

* Good, because terminology and workflows are concrete from day one.
* Neutral: AT, CH and INT follow as separate profiles.
