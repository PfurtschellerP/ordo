# Licence the software under AGPL-3.0-or-later

## Context and Problem Statement

Modified versions must stay open, including when offered as a hosted service.

## Considered Options

* MIT/Apache-2.0
* MPL-2.0
* GPL-3.0
* AGPL-3.0-or-later
* EUPL-1.2

## Decision Outcome

Chosen option: "AGPL-3.0-or-later", because it closes the hosting loophole of the GPL while allowing unchanged and in-house use.

### Consequences

* Good, because improvements by hosters must be published.
* Neutral: no licence can force contributions back upstream.
