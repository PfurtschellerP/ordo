# Accessibility target EN 301 549 / WCAG 2.2 AA

## Context and Problem Statement

Public bodies in Germany and the EU must use accessible ICT; responders work under difficult conditions (A11Y-1…11).

## Considered Options

* Best effort
* WCAG 2.1 AA
* EN 301 549 with WCAG 2.2 AA

## Decision Outcome

Chosen option: "EN 301 549 with WCAG 2.2 AA for all outputs", because it covers both the currently harmonised version (WCAG 2.1) and the new v4.1.1.

### Consequences

* Good, because public bodies can use ORDO and publish their accessibility statement.
* Bad, because accessibility testing becomes part of every release.
