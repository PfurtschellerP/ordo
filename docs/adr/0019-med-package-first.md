# Med package first in the MVP

## Context and Problem Statement

The MVP needs one service package and low-risk field tests.

## Considered Options

* Fire first
* Med first (without ePCR)

## Decision Outcome

Chosen option: "Med first: patients and triage, UHS, transport planning; ePCR later", because planned operations (events) allow regular field tests without risk to real emergencies.

### Consequences

* Good, because test opportunities are plannable.
* Neutral: Fire follows in phase 2.
