# Tactical symbols of the DE profile (MAP-3)

The symbols follow the BBK's *Taktische Zeichen im Bevölkerungsschutz – Empfehlungen zur
Einführung einer FwDV 102/DV 102* (1st edition, May 2024; see
[docs/standards.md](../../../docs/standards.md)). `symbols.json` lists them. Symbols with a
`spec` are generated by [tools/symbols](../../../tools/symbols) with
`@taktische-zeichen/core` ([ADR-0054](../../../docs/adr/0054-tactical-symbols-generated.md)).
Symbols without one are drawn by hand, because the library cannot draw them yet; each file
names its source.

## Comparison with the BBK edition of 2024

Compared on 2026-11-10. Numbers are the document's sections.

| Symbol | BBK | Result |
|---|---|---|
| Colours of organisations | 2.1–2.8 | Match: fire red, aid organisations white (also municipal ambulance services), THW blue, command yellow, police green, other public safety orange |
| RTW, KTW, NEF, ITW | F.2.1, F.2.3, F.2.4 | Match: vehicle, medical sign, short name top left. NEF with the physician sign (second form). ITW is not in the document; drawn like RTW |
| Ambulance service vehicle, medical unit (by service) | 4.6.1, F.1.6 | Match, without unit size |
| RTH | 1.4, 5.1.4.2, F.2.6–F.2.7 | Drawn by hand: the library's helicopter is the older rotor sign, the 2024 edition uses the aircraft dome with the rotary-wing mark |
| UHS | F.3.3 | Drawn by hand: the library cannot put "UHS" outside the circle |
| Patientenablage | F.3.1 | Drawn by hand: the library has no double arrow |
| Behandlungsplatz | F.3.5 | Match: fixed place with the physician sign; capacity not shown |
| ELW, HLF, LF, DLK | C.2.2, C.2.8–C.2.9, C.2.14–C.2.16 | Match: short name top left, ELW at the bottom under the command bar |
| Fire, THW, police, civil-protection and civil-defence vehicle (by service) | 2.x, 5.1.1.1 | Match. Civil-protection units of aid organisations or fire services would be white or red, not orange; units are matched by service only |
| Incident command (EL), sector (EAL), sub-sector (UEAL) | D.1.1, D.1.4–D.1.6 | Match: command post in yellow with the command bar. Before, the older flag with a pole |
| Medical command (SanEL), transport organisation (TO) | D.1.1, 2.4, P.7 | Same form as other command posts, with the short names used in the state concepts; the document has no own sign for them |
| Incident location | – | Not in the 2024 edition (it shows damage and hazards by kind, 5.8); kept as the DV 102 *Anlass* sign until the map editor draws damage and hazards (MAP-4) |

Open points: unit sizes and crew strength, the "with physician" variants (F.3.2, F.3.4),
and capacity next to places (F.3.5) are not shown yet.
